# CodeAlpha Artificial Intelligence Internship

Welcome to my repository for the **Artificial Intelligence Internship at CodeAlpha**. This repository contains the projects I developed as part of my internship, focusing on practical applications of Python, language technologies, and intelligent systems.

## Projects

### Task 1: Language Translator

A web-based application that translates text between supported languages using Python and Django.

**Key Features**
- Translation between supported languages
- Source and target language selection
- Language swapping
- Copy translated text
- Text-to-speech for translated output
- Responsive user interface
- Input validation and error handling

**Technologies Used:** Python, Django, HTML, CSS, JavaScript, Requests.

### Task 2: ShopAssist Chatbot

A Python-based chatbot designed to answer common customer questions and assist users with store-related enquiries.

**Key Features**
- Automated responses to supported questions
- Greeting and thank-you recognition
- Text preprocessing
- Basic question handling
- Customer-support-style interactions

**Technologies Used:** Python, Natural Language Processing concepts.
